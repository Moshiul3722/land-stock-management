# localhost-এ লগইন করার নিয়ম

এই সফটওয়্যারে লগইন হয় শুধু ইমেইলে পাঠানো কোড (OTP) দিয়ে। নিজের কম্পিউটারে (localhost) কোডটি ইমেইলে যায় না, একটি log ফাইলে লেখা হয়। নিচের ধাপগুলো মেনে লগইন করুন।

---

## ধাপ ১: সাইট চালু আছে কিনা দেখুন

ব্রাউজারে খুলুন: **http://localhost:8000**

- লগইন পাতা এলে **ধাপ ২-এ** যান।
- "This site can't be reached" দেখালে সাইট বন্ধ আছে। Terminal-এ নিচের কমান্ড চালিয়ে পাতাটি আবার খুলুন:

```bash
cd /Volumes/MacSSD/AI-Engineering/land-stock-management && php artisan serve
```

এই Terminal window খোলা রাখুন। বন্ধ করলে সাইটও বন্ধ হয়ে যাবে।

---

## ধাপ ২: ইমেইল দিন

লগইন পাতায় ব্যবহারকারীর **নিবন্ধিত ইমেইল** লিখে **OTP পাঠান** চাপুন।

- "কোড পাঠানো হয়েছে" দেখালে **ধাপ ৩-এ** যান।
- "এই ইমেইলটি নিবন্ধিত বা অনুমোদিত নয়" দেখালে ইমেইলটি **localhost-এর database-এ** নেই, অথবা ব্যবহারকারী active নন। live সাইটের ব্যবহারকারী তালিকা আর localhost-এর তালিকা আলাদা।

---

## ধাপ ৩: কোড বের করুন

ধাপ ২-এর বোতাম চাপার **পরে**, একটি **নতুন** Terminal window খুলে চালান:

```bash
grep -oE "OTP\): [0-9]{6}" /Volumes/MacSSD/AI-Engineering/land-stock-management/storage/logs/laravel.log | tail -1
```

ফলাফল দেখতে এমন হবে: `OTP): 189888`। এখানে **শেষের ৬টি অঙ্কই** কোড।

---

## ধাপ ৪: কোড বসান

৬টি ঘরে কোডটি বসিয়ে **যাচাই করে প্রবেশ করুন** চাপুন। Dashboard খুলে যাবে। ✅

---

## "কোডটি সঠিক নয়" দেখালে

1. **আবার পাঠান** চাপুন। অপেক্ষার সময় দেখালে সেটি শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
2. **তারপর** ধাপ ৩-এর কমান্ড আবার চালান।
3. নতুন কোডটি বসান।

---

## তিনটি নিয়ম মনে রাখুন

| নিয়ম | কারণ |
|---|---|
| **আগে বোতাম চাপুন, তারপর কমান্ড চালান** | প্রতিবার বোতাম চাপলে নতুন কোড আসে, আর আগের কোড বাতিল হয়ে যায় |
| **৩ মিনিটের মধ্যে কোড বসান** | এরপর কোডের মেয়াদ শেষ হয়ে যায় |
| **একটি কোডে সর্বোচ্চ ৫ বার চেষ্টা** | এর বেশি ভুল হলে নতুন কোড নিতে হবে। ১০ মিনিটে সর্বোচ্চ ৫টি কোড চাওয়া যায় |
